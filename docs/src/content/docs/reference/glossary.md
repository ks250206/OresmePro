| 用語                   | 意味                                                                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Wave**               | 名前の付いた数値(またはテキスト)の配列。値のほか、X(と Y)のスケーリング(開始値・刻み・単位)、値の単位、ノート、必要なら数式を持つ。Igor Pro の wave と同じ考え方 |
| **スケーリング**       | 点番号から X の値を決める開始値と刻み(`x = x0 + i·dx`)。X wave を使わずに横軸を持てる                                                                            |
| **X wave**             | 横軸に使う別の wave。不等間隔のデータに使う                                                                                                                      |
| **テキスト wave**      | 文字列の wave。グラフではカテゴリ軸になる                                                                                                                        |
| **データフォルダ**     | wave をまとめる階層。パスは `run1:spectrum` のように `:` で区切る。根は `root`                                                                                   |
| **試料の属性**         | データフォルダか wave に付ける、名前付きの数値・文字(膜厚、組成、温度など)。wave はフォルダの属性を受け継ぐ                                                      |
| **数式(formula)**      | 他の wave から値を計算する式(`ratio := a / b`)。元が変わると自動で計算し直す                                                                                     |
| **Experiment(実験)**   | wave・グラフ・テーブル・Procedure・ファイル・結果・パッケージの記録など、作業のすべて。ブラウザに自動保存され、`.oresme` ファイルとして保存・共有できる          |
| **グラフ / トレース**  | グラフは 1 つのウィンドウ。トレースはその中の 1 本の線(またはマーカー)で、Y wave と、X wave かスケーリングから描く                                               |
| **軸**                 | left・bottom・right・top の 4 つと、追加した自由軸。範囲・対数・目盛り・ラベルを持つ                                                                             |
| **プロット領域**       | 軸で囲まれた部分。大きさを Auto・Absolute・Aspect・Plan・Per unit で決められる                                                                                   |
| **カーソル**           | トレース上の点に置く印 A(丸)と B(四角)。位置と差を読み、範囲の指定にも使う                                                                                       |
| **注釈**               | グラフ上の凡例・テキスト・カラースケール・タグ                                                                                                                   |
| **スタイル**           | グラフの見た目(フォント・線・色・目盛りなど)に名前を付けたもの。データは含まない                                                                                 |
| **グラフテンプレート** | wave を抜いたグラフ。別のデータで同じグラフを作る                                                                                                                |
| **連動(Link)**         | 複数のグラフの軸範囲とカーソルを一緒に動かす設定                                                                                                                 |
| **ページレイアウト**   | 紙の上にグラフとテキストを並べる図。PDF などに書き出す                                                                                                           |
| **テーブル**           | wave を列として並べるウィンドウ。セルを直接編集できる                                                                                                            |
| **Procedure**          | 実験に保存される Python ファイル。名前がモジュール名になり、`import` できる                                                                                      |
| **Note(ノート)**       | 実験に保存される Markdown の文章。整形して表示する                                                                                                               |
| **パネル**             | ボタンや入力欄で Action を呼ぶ、自作の操作画面                                                                                                                   |
| **Close と Kill**      | Close はウィンドウを閉じて中身を残し、Windows メニューから開き直せる。Kill は中身ごと削除する                                                                    |
| **結果(Result)**       | フィットなどの解析の記録。係数・不確かさ・条件・入力の指紋と、作った曲線のコピー(`results:<名前>`)を持つ                                                         |
| **Action**             | `core.fit` のように名前と型付きの引数で登録された解析。パネル・テンプレート・プラグインから呼ぶ                                                                  |
| **解析テンプレート**   | Action の手順に名前を付けたもの。多数の試料に順に適用する                                                                                                        |
| **Run**                | テンプレートを試料に実行した記録。試料ごとの状態・エラー・結果を持ち、失敗したものだけやり直せる                                                                 |
| **プラグイン**         | Action・テンプレート・スタイルなどをまとめて追加する拡張。サンドボックスで動く                                                                                   |
| **パッケージ**         | Python のライブラリ。同梱・Pyodide 配布物・PyPI から入れ、実験ごとに記録される                                                                                   |
| **Pyodide**            | ブラウザの中で動く Python(WebAssembly)。データはサーバーに送られない                                                                                             |
| **履歴**               | コマンドウィンドウに残る入力と出力。画面の操作も、同じことをする Python の行として残る                                                                           |
| **Undo**               | 実験への変更を戻す。`op.atomic()` の中の変更は 1 回でまとめて戻る                                                                                                |
