macOS では **Ctrl** を **⌘** に、**Alt** を **Option** に読み替えてください。

## アプリ全体

| 操作                      | すること                                                                                     |
| ------------------------- | -------------------------------------------------------------------------------------------- |
| **Ctrl+S**                | Save Experiment As…(ファイル名を入れて保存)                                                  |
| **Ctrl+Z** / **Ctrl+Y**   | Undo / Redo(macOS の Redo は **⇧⌘Z**)                                                        |
| **Ctrl+A**                | 最前面のグラフの全軸を自動範囲に。ページレイアウトでは全項目を選択                           |
| **Ctrl+I**                | 最前面のグラフのカーソル情報の欄を出し入れ                                                   |
| **Ctrl+C**                | 最前面のグラフを PNG 画像としてクリップボードにコピー(文字を選んでいるときは文字のコピー)    |
| **Ctrl+C**(Python 実行中) | Python を止める                                                                              |
| デスクトップを右クリック  | メニューバーと同じメニュー                                                                   |
| ファイルをドロップ        | CSV・Excel は Load Data ダイアログ、Igor・Parquet・HDF5 はそのまま読み込み、`.oresme` は開く |

## ウィンドウ

| 操作                         | すること                                             |
| ---------------------------- | ---------------------------------------------------- |
| タイトルバーをドラッグ       | 移動                                                 |
| 縁・角をドラッグ             | 大きさを変える(プロット領域が固定の向きは変わらない) |
| タイトルバーをダブルクリック | 名前を変える                                         |
| 左上の **×**                 | Close(中身を残して閉じる)か Kill かを選ぶ            |
| **Alt** を押しながら **×**   | 確認なしで Kill                                      |

## グラフ

| 操作                                       | すること                                                              |
| ------------------------------------------ | --------------------------------------------------------------------- |
| プロット領域をドラッグ                     | 範囲を囲む。メニューから Expand / Horiz Expand / Vert Expand / Shrink |
| **Alt** を押しながらドラッグ               | パン(表示範囲を動かす)                                                |
| ホイール                                   | カーソル位置を中心に拡大・縮小。軸の上では、その軸だけ                |
| 軸をダブルクリック                         | Modify Axis                                                           |
| トレースをダブルクリック                   | Modify Trace Appearance(画像・等高線ではそれぞれの設定)               |
| 凡例・テキストをダブルクリック             | その注釈を編集。ドラッグで移動                                        |
| 余白をダブルクリック                       | Modify Graph                                                          |
| カーソル(A は丸、B は四角)をドラッグ       | 別の点へ動かす                                                        |
| **←** / **→**                              | カーソルを 1 点動かす(**Shift** で 10 点)                             |
| 右クリック                                 | カーソルの設置、Modify 各種、スタイル、テンプレート、Link Graphs など |
| **Alt+T**(Show Tools)                      | 図形を描くツールを出し入れする。描き方は「図形を描く」のガイド        |
| **Ctrl+A**(ツールを出しているとき)         | すべての図形を選ぶ(ツールがないときは軸の自動範囲)                    |
| **Shift**-クリック(ツールを出しているとき) | 図形を選択に足す・外す                                                |

連動したグラフ(Link Graphs)では、拡大・パン・カーソルが他のグラフにも伝わります。

## テーブル

| 操作                       | すること                                                |
| -------------------------- | ------------------------------------------------------- |
| 矢印キー / **Tab**         | セルを移動                                              |
| **Enter** / **F2**         | 編集を始める。編集中の **Enter** で確定                 |
| **Escape**(編集中)         | 編集をやめる                                            |
| **Delete** / **Backspace** | 選んだセルを消す                                        |
| 右クリック                 | 行の挿入・削除、wave の表示・スケーリング・名前変更など |

## コマンド入力

| 操作                    | すること                                                       |
| ----------------------- | -------------------------------------------------------------- |
| **Enter**               | 実行                                                           |
| **Shift+Enter**         | 改行                                                           |
| **↑** / **↓**           | 入力の先頭に一致する履歴を呼び出す                             |
| **Ctrl+R**              | 履歴を検索                                                     |
| **Tab**                 | 補完(行頭ではインデント)                                       |
| **Ctrl+E** / **Ctrl+→** | 薄く出ている履歴の候補を受け入れる(**Ctrl+→** は 1 語ずつ)     |
| `%pip install name`     | パッケージを入れる(`%pip list / freeze / show / uninstall` も) |

## Procedure のエディタ

| 操作                    | すること                       |
| ----------------------- | ------------------------------ |
| **Ctrl+Enter**          | Procedure 全体を実行           |
| **Shift+Enter**         | 選択範囲(または現在の行)を実行 |
| **Shift+Alt+F**         | 整形(Ruff)                     |
| **Ctrl+/**              | 行のコメント切り替え           |
| **Ctrl+]** / **Ctrl+[** | インデント / アンインデント    |
| **Ctrl+F** / **Ctrl+G** | 検索と置換 / 行へ移動          |
| **Ctrl+Shift+M**        | 問題の一覧(Ruff の指摘)        |

## Data Browser

| 操作                                   | すること                                                             |
| -------------------------------------- | -------------------------------------------------------------------- |
| 検索欄に入力                           | 名前・単位・型・ノートに含む wave だけを表示(`text` でテキスト wave) |
| 検索欄で **↓** / **Enter**             | 一覧の最初の wave へ                                                 |
| **↑** / **↓** / **Home** / **End**     | 選択を移動(**Shift** で追加)                                         |
| **Enter**                              | 選んだ wave をテーブルに表示                                         |
| **Ctrl+A** / **Escape**                | 表示中の全 wave を選択 / 選択を解除                                  |
| クリック・**Shift**・**Ctrl**+クリック | 選択(範囲・追加)                                                     |
| ダブルクリック                         | テーブルに表示                                                       |
| フォルダへドラッグ                     | wave を移動                                                          |

## ページレイアウト

| 操作                               | すること                 |
| ---------------------------------- | ------------------------ |
| クリック・**Shift**+クリック・囲む | 項目を選択               |
| ドラッグ                           | 移動(複数選択はまとめて) |
| **Delete** / **Backspace**         | 選んだ項目を外す         |
| **Escape**                         | 選択を解除               |
