## Python

| 症状                                                                     | 原因と対処                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ステータスバーが「Starting Python…」「Loading NumPy and IPython…」のまま | 初回は Python とパッケージの取得に時間がかかります。2 回目以降はブラウザに保存されたものを使います。進まないときはページを再読み込みしてください                                                                                                                                                        |
| 長い処理が止まらない                                                     | **Python → Interrupt**(**Ctrl+C**)。もう一度押すと Python を再起動します。wave やグラフは残ります                                                                                                                                                                                                       |
| `ModuleNotFoundError`                                                    | Pyodide に同梱されたもの(SciPy、pandas など)は `import` するだけで入ります。それ以外は `%pip install name` か **Python → Packages…** で入れます                                                                                                                                                         |
| `%pip install` が「No wheel that runs in the browser for: …」            | そのパッケージは独自のコンパイル済みコードを持ち、Pyodide 向けの wheel がありません(例: pymatgen-core、Numba、PyTorch)。ブラウザでは動かないので、別の Python 環境を使ってください。対応パッケージは [Packages in Pyodide](https://pyodide.org/en/stable/usage/packages-in-pyodide.html) を見てください |
| オフラインでパッケージが入らない                                         | 初めて入れるパッケージはネットワークが必要です。一度入れたもの、同梱のもの(**Python → Keep Optional Packages for Offline Use** で先に保存できます)はオフラインでも入ります                                                                                                                              |
| 実験を開くと「packages from PyPI … Install them?」                       | 他の人の `.oresme` が PyPI のパッケージを使っています。import するとそのコードが動くため確認します。あとで入れるには **Python → Packages… → Install Them**                                                                                                                                              |
| `await` が使えない                                                       | コマンド入力ではそのまま `await` を書けます。Procedure の中(`p.run()`)では使えないので、パッケージは実験に記録して開くときに入れるか、コマンド入力で入れます                                                                                                                                            |

## データとグラフ

| 症状                             | 原因と対処                                                                                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| wave が削除できない(in use by …) | グラフやテーブルが使っています。そのトレース・列を外すか、ウィンドウを Kill します。閉じた(Close)ウィンドウも wave を使い続けます                            |
| CSV の列が文字列になる           | Load Data ダイアログのプレビューで列の型を指定します。定型のファイルはプリセットに保存できます                                                               |
| フィットの不確かさが NaN         | パラメータが互いに独立に決まっていません(結果の理由に「uncertainties could not be estimated」と出ます)。パラメータを減らすか hold し、範囲を見直してください |
| グラフの大きさが変えられない     | プロット領域の幅か高さが Auto 以外に固定されています(**Modify Graph → Plot area**)                                                                           |
| 書き出した図と画面の大きさが違う | 表示倍率(**Modify Graph → Magnification**)は画面だけに効きます。書き出しは等倍です                                                                           |
| ウィンドウが見当たらない         | 閉じた(Close)ウィンドウは **Windows** メニューの種類別の一覧に「(closed)」で残っています                                                                     |

## 保存

| 症状                                                                  | 原因と対処                                                                                                                                                                                                            |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「The Experiment Is Not Saved」と出て別の実験に移れない               | ブラウザに保存できませんでした(容量不足など)。**Try Again** で再試行、**Save as File…** で `.oresme` に保存、または保存せずに移動を選びます                                                                           |
| ステータスバーに「The saved experiment could not be read: not saved」 | 保存されたファイルの一部が欠けています。読めた分は戻っています。**Go Back to Backup**(前回の状態)か **Start Afresh**(いまの状態で保存し直す)を選びます。選ぶまで上書き保存はしません                                  |
| ステータスバーに「Not saved: …」                                      | ブラウザに保存できませんでした。**Try Again** で再試行します。容量が足りないときは不要な実験を **File → Experiments…** で削除するか、ファイルに保存してください                                                       |
| ブラウザのデータを消したら実験が消えた                                | 自動保存はブラウザ(OPFS)の中です。持ち出すものは **File → Save Experiment As…** でファイルに保存してください                                                                                                          |
| ステータスバーに「Open in another tab: not saved here」               | 同じ実験を別のタブでも開いています。保存するのは 1 つのタブだけです。**Save Here Instead** でこのタブが保存を引き継ぎます。保存していないタブで変更してから別の実験を開いたりタブを閉じたりすると、その前に確かめます |
