見本のプラグイン [xps](https://github.com/ks250206/OresmePro/tree/main/examples/plugins/xps) は、XPS スペクトルのピークモデルを CasaXPS と同じ手順で作る **XPS Peak Fitting** ウィンドウを持ちます。領域(Region)を決め、その下に背景を引き、合成成分(Components)を置いてフィットします。成分はスペクトルの上でドラッグして動かせ、表で値と制約を直接書き換えられます。計算はプラグインのサンドボックスの中で動き、ウィンドウはアプリが描きます(プラグインの[モデル編集ウィンドウ](../plugins/#モデル編集ウィンドウeditors))。

## 入れる・開く

**Python → Plugins…** の **Install from GitHub…** に `https://github.com/ks250206/OresmePro/tree/main/examples/plugins/xps` を入れて **Fetch** し、**Install** します(フォルダからなら **Install from Folder…**)。

Data Browser でスペクトル(強度の1次元 wave)を選んでから **Analysis → XPS Peak Fitting…** を選ぶと、その wave で開きます。上部で **Spectrum** と **Energy**(XY データなら X の wave、そうでなければ **X scaling**)を選びます。

ウィンドウの中身(スペクトルごとの領域・設定・成分・制約)は Experiment に保存され、開き直すと残したところから続きます。それがなく、そのスペクトルを前にフィットしていれば、最後の結果の領域・設定・成分・制約が戻ります。

## スペクトルの上で操作する

プロットは結合エネルギーの軸が右から左へ増える向きで、上に残差を表示します。編集するたびに、プラグインが背景・各成分・エンベロープ(赤)・残差を計算し直して描きます。

| 操作                                    | 結果                                                                         |
| --------------------------------------- | ---------------------------------------------------------------------------- |
| 青い破線(領域の端)をドラッグ            | 領域を変える。領域の外の点は灰色                                             |
| ピークの上をダブルクリック              | そこに成分を加える(高さはデータから)                                         |
| 成分の頂上の四角をドラッグ              | 左右で位置、上下で高さ(面積)を変える                                         |
| 選んだ成分の◇(半値の位置)をドラッグ     | FWHM を変える(高さはそのまま)                                                |
| 成分をクリック / 表の列見出しをクリック | 成分を選ぶ                                                                   |
| マウスホイール                          | 横に拡大・縮小。**Range** で領域、**All** でスペクトル全体を表示             |
| Delete                                  | 選んだ成分を消す                                                             |
| Ctrl+Z / Ctrl+Shift+Z(⌘Z / ⇧⌘Z)         | ウィンドウの中の編集を元に戻す / やり直す(フィットも 1 回の編集として戻せる) |

制約で別の成分に結んだパラメータ(下の `A+1.5` など)はドラッグでは動かず、結んだ先に付いて動きます。

## Components: 成分の表

CasaXPS の Components ページと同じく、成分ごとに列(A, B, C, …)が並びます。

| 行                                | 内容                                                                       |
| --------------------------------- | -------------------------------------------------------------------------- |
| Name                              | 成分の名前(C-C、Ti 2p3/2 など)。空なら文字                                 |
| Line shape                        | 線形。`GL(m)`、`SGL(m)`、`GL(m)T(k)`、`SGL(m)T(k)`、`LA(α,β)`(下の表)      |
| Position / FWHM / Area            | 位置(eV)、幅のパラメータ F(eV)、面積。フィットのあとは求まった値になります |
| Position / FWHM / Area constraint | 制約(下の表)                                                               |
| Gauss (eV)                        | 線形に畳み込むガウス関数の FWHM(0 なら畳み込まない)。装置関数の広がりに    |
| RSF                               | 相対感度係数。Report の **% Area/RSF** に使います                          |

制約の書き方:

| 書き方           | 意味                                                     |
| ---------------- | -------------------------------------------------------- |
| (空)             | 自由。位置は領域の中、FWHM は 0.05〜20 eV、面積は 0 以上 |
| `284.5, 285.5`   | その範囲の中で自由                                       |
| `fixed`          | 表の値に固定                                             |
| `A`              | 成分 A の同じパラメータと同じ値(同じ FWHM など)          |
| `A+1.5`, `A-1.5` | 成分 A の値からずらす(スピン軌道分裂、化学シフト)        |
| `A*0.5`, `A/2`   | 成分 A の値の倍数(面積比: 2p1/2 は 2p3/2 の 1/2、など)   |

左のボタン:

- **Create**: 領域の中で、データが今のモデルより最も上に出ているところに成分を加えます
- **Copy**: 選んだ成分の写しを、その FWHM だけ高い位置に加えます
- **Doublet**: 選んだ成分 X のスピン軌道の相手を加えます。位置は `X+Δ`、FWHM は `X`、面積は `X*比` に結ばれます。Δ(eV)と比(p 1:2、d 2:3、f 3:4)はボタンの下で選びます
- **Delete**: 選んだ成分を消します。それに結ばれていた制約は外れ、その時点の値が残ります

**Fit Components** でフィットし、求まった値を表に入れます。

## Settings: 領域・エネルギー・背景

| 項目                   | 内容                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Region (eV)            | 領域の結合エネルギー。**All the Data** でスペクトル全体                                                                    |
| Energies are           | binding か kinetic。kinetic なら **Photon energy**(Al Kα 1486.6 eV、Mg Kα 1253.6 eV)から BE = hν − KE                      |
| Charge correction (eV) | 帯電補正。すべての結合エネルギーに足します。C 1s が 285.6 eV に出て 284.8 eV にしたいなら −0.8                             |
| Background             | **Shirley**(通った面積に比例して上がる)、**Linear**、**Tougaard**(普遍断面積 C = 1643 eV²、B はデータに合わせる)、**None** |
| Average width          | 背景の両端の高さを、端の何点の平均にするか(CasaXPS の Av Width)                                                            |
| Weighting              | poisson(各点を 1/√counts で重み付け)か unit                                                                                |

背景はデータから求め、フィットの間は固定します(CasaXPS と同じ)。

## Report: 結果

各成分の位置・FWHM・真の半値全幅(Width)・面積とその標準偏差、RSF、面積/RSF の割合、χ² と縮約 χ² を表示します。**Copy** でタブ区切りの表としてコピーできます。不確かさは解での Jacobian から(残差の分散で尺度合わせ)求め、背景の不確かさは含みません。

## 作られるもの

フィットするたびに、スペクトルの隣に領域の範囲の wave を作ります: `<名前>_region`(データ)、`_background`、`_comp_A`, `_comp_B`, …(背景に載せた各成分)、`_envelope`、`_residual`、X の wave を使ったときは `_be`(結合エネルギー)。グラフ `XPSFit` に、反転した結合エネルギー軸、上に残差、凡例付きで表示します。結果は **Analysis → Results…** に `Plugin0`, `Plugin1`, … として残ります。

このウィンドウからフィットし直すと、前のフィットが作った wave のうち、その後に変えていないものを同じ名前で作り直し、グラフも(色や軸を変えたものはそのまま)更新します。成分を減らしたときは、もう作らない成分の wave をグラフから外して消します。変えた wave や名前を変えた wave には触れず、新しい名前で作ります([プラグインの規則](../plugins/#使う))。各結果は、作った wave のコピーを `results:<結果名>` に残します。

## Python から

ウィンドウのフィットは次の呼び出しと同じで、履歴に残ります。

```python
op.invoke("plugin.xps.xps_fit", {
    "spectrum": "C1s",
    "region": [281, 293],
    "components": [
        {"name": "C-C", "position": 284.8, "fwhm": 1.1, "area": 3000},
        {"name": "C-O", "position": 286.3, "area": 900,
         "constraints": {"position": "A+1.5", "fwhm": "A"}},
    ],
    "shift": -0.4,
}, replace=True)
```

`replace=True` を省くと、前の wave に触れず、新しい名前で作ります。

## 定量(XPS Quantification)

**Analysis → XPS Quantification…** は、複数の領域の面積と相対感度係数(RSF)から原子 % を求めるウィンドウです(プラグインの [view](../plugins/#部品で組み立てる画面view))。

- **Spectra** で、サーベイ 1 本か、領域ごとのナロースキャンを選びます(**Add Spectrum** で増やす)。エネルギーが X scaling でないときは、それぞれの **Energy** も選びます(全部に付けるか、どれにも付けないか)
- スペクトルを押すと、その位置を中心に幅 8 eV の領域が加わります。表で名前・範囲・RSF を書き換え、**Add Row** で行を足します。`C 1s`、`N 1s`、`O 1s`、`F 1s` と名付けた領域は、RSF が空なら Al Kα の Scofield の値(C 1s を 1 とする)が入ります。装置の透過関数や脱出深さは入っていないので、必要なら **KE exponent** を使うか、装置の RSF を書いてください
- 領域の境はプロット上の縦線で、ドラッグで動かせます(Ctrl+Z で戻せます)。編集するたびに、背景(Settings の **Background**)の上の面積と原子 % が表に出ます。各領域は、その範囲を含む最初のスペクトルから取ります。プロットには **Show** で選んだスペクトルと背景、そのスペクトルにある領域の境が出ます
- **Quantify** で Action `quantify` を `replace=True` で実行し、背景の wave と結果(`Plugin0` など。係数が各領域の原子 %)を残します。履歴には `op.invoke("plugin.xps.quantify", {...}, replace=True)` と残ります

## 線形

u = (BE − E)/F、m は %、u > 0 が高結合エネルギー側です(CasaXPS マニュアル 2.3.15 rev 1.3、p. 55 と p. 301)。

| 線形         | 式                                                                                   |
| ------------ | ------------------------------------------------------------------------------------ |
| `GL(m)`      | exp(−4 ln2 (1 − m/100) u²) / (1 + 4 (m/100) u²)(ガウスとローレンツの積)              |
| `SGL(m)`     | (1 − m/100) exp(−4 ln2 u²) + (m/100) / (1 + 4u²)(和)                                 |
| `GL(m)T(k)`  | 高結合エネルギー側で GL + (1 − GL) exp(−k u)。k が小さいほど裾が長い                 |
| `SGL(m)T(k)` | 同じく SGL に裾を付けたもの                                                          |
| `LA(α,β)`    | 高結合エネルギー側で (1 + 4u²)^(−α)、反対側で (1 + 4u²)^(−β)。金属の非対称なピークに |

- 面積は線形全体の面積です。ガウス関数を畳み込んでも面積は変わりません
- F が真の半値全幅になるのは GL(0)、GL(100)、SGL(m) で裾もガウスもないときだけです(GL(30) では 0.961 F)。真の幅は Report の **Width** に出ます
- CasaXPS の `LA(α,β,m)` の m は換算が公開されていないため、代わりに **Gauss** にガウス関数の FWHM を eV で与えます

## 限界

- 1 つのスペクトルの 1 つの領域をフィットします。サーベイからの定量(複数の領域の面積と RSF からの原子濃度)は、上の [XPS Quantification](#定量xps-quantification) を使います
- 背景はフィットの間は固定です(active Shirley はありません)。不確かさに背景の不確かさは入りません
