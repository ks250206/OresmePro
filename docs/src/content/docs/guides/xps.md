**Analysis → XPS Peak Fitting…** は、XPS スペクトルのピークモデルを CasaXPS と同じ手順で作るウィンドウです。領域(Region)を決め、その下に背景を引き、合成成分(Components)を置いてフィットします。成分はスペクトルの上でドラッグして動かせ、表で値と制約を直接書き換えられます。フィットするたびに `op.xps_fit(...)` として履歴に残り、結果は **Analysis → Results…** に `XPS0`, `XPS1`, … として残ります。

## 開く

Data Browser でスペクトル(強度の1次元 wave)を選んでから **Analysis → XPS Peak Fitting…** を選ぶと、その wave で開きます。ウィンドウ上部で次を選びます。

| 項目              | 内容                                                                                                                 |
| ----------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Spectrum**      | フィットする wave                                                                                                    |
| **Energy**        | エネルギーの X wave(XY データのとき)。**X scaling** ならスペクトルの X スケーリング                                  |
| binding / kinetic | エネルギーが結合エネルギーか運動エネルギーか。kinetic なら **hν**(Al Kα 1486.6 eV、Mg Kα 1253.6 eV)から BE = hν − KE |
| **Shift**         | 帯電補正(eV)。すべての結合エネルギーに足します。C 1s が 285.6 eV に出て 284.8 eV にしたいなら −0.8                   |

そのスペクトルを前にフィットしていれば、最後の結果の領域・背景・成分・制約が戻ります。

## スペクトルの上で操作する

プロットは結合エネルギーの軸が右から左へ増える向きで、上に残差を表示します。編集するたびに背景・各成分・エンベロープ(赤)・残差がその場で描き直されます。

| 操作                                    | 結果                                                                       |
| --------------------------------------- | -------------------------------------------------------------------------- |
| 青い破線(領域の端)をドラッグ            | 領域を変える。領域の外の点は灰色                                           |
| ピークの上をダブルクリック              | そこに成分を加える(高さはデータから)                                       |
| 成分の頂上の四角をドラッグ              | 左右で位置、上下で高さ(面積)を変える                                       |
| 選んだ成分の◇(半値の位置)をドラッグ     | FWHM を変える(高さはそのまま)                                              |
| 成分をクリック / 表の列見出しをクリック | 成分を選ぶ                                                                 |
| マウスホイール                          | 横に拡大・縮小。**Region** で領域、**All** でスペクトル全体を表示          |
| Delete                                  | 選んだ成分を消す                                                           |
| Ctrl+Z / Ctrl+Shift+Z(⌘Z / ⇧⌘Z)         | ウィンドウの中の編集を元に戻す / やり直す(フィットも1回の編集として戻せる) |

制約で別の成分に結んだパラメータ(下の `A+1.5` など)はドラッグでは動かず、結んだ先に付いて動きます。

## Components: 成分の表

CasaXPS の Components ページと同じく、成分ごとに列(A, B, C, …)が並びます。

| 行                                | 内容                                                                       |
| --------------------------------- | -------------------------------------------------------------------------- |
| Name                              | 成分の名前(C-C、Ti 2p3/2 など)                                             |
| Line shape                        | 線形。`GL(m)`、`SGL(m)`、`GL(m)T(k)`、`SGL(m)T(k)`、`LA(α,β)`(下の表)      |
| Position / FWHM / Area            | 位置(eV)、幅のパラメータ F(eV)、面積。フィットのあとは求まった値になります |
| Position / FWHM / Area constraint | 制約(下の表)                                                               |
| Gauss (eV)                        | 線形に畳み込むガウス関数の FWHM(0 なら畳み込まない)。装置関数の広がりに    |
| RSF                               | 相対感度係数。**% Area/RSF** の計算に使います                              |
| % Area/RSF                        | 最後のフィットでの、面積/RSF の割合                                        |

制約の書き方:

| 書き方           | 意味                                                        |
| ---------------- | ----------------------------------------------------------- |
| (空)             | 自由。位置は領域の中、FWHM は 0.05〜20 eV、面積は 0 以上    |
| `284.5, 285.5`   | その範囲の中で自由                                          |
| `fixed`          | 表の値に固定                                                |
| `A`              | 成分 A の同じパラメータと同じ値(同じ FWHM など)             |
| `A+1.5`, `A-1.5` | 成分 A の値からずらす(位置の差: スピン軌道分裂、化学シフト) |
| `A*0.5`, `A/2`   | 成分 A の値の倍数(面積比: 2p1/2 は 2p3/2 の 1/2、など)      |

左のボタン:

- **Create**: 領域の中で、データが今のフィットより最も上に出ているところに成分を加えます
- **Copy**: 選んだ成分の写しを 1 eV 高い位置に加えます
- **Doublet**: 選んだ成分のスピン軌道の相手を加えます。位置は `X+Δ`、FWHM は `X`、面積は `X*比` に結ばれます。Δ(eV)と比(p 1:2、d 2:3、f 3:4)はボタンの下で選びます
- **Delete**: 選んだ成分を消します。それに結ばれていた制約は外れ、その時点の値が残ります

**Fit Components** でフィットし、求まった値を表に入れます。**Draw** はフィットせずに、今の成分で wave とグラフを作ります。

## Region: 領域と背景

| 項目         | 内容                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| From / To    | 領域の結合エネルギー。**Whole Spectrum** でスペクトル全体                                                                  |
| Background   | **Shirley**(通った面積に比例して上がる)、**Linear**、**Tougaard**(普遍断面積 C = 1643 eV²、B はデータに合わせる)、**None** |
| 平均する点数 | 背景の両端の高さを、端の何点の平均にするか(CasaXPS の Av Width)                                                            |
| Weighting    | **Poisson**(各点を 1/√counts で重み付け)か **None**                                                                        |

背景はデータから求め、フィットの間は固定します(CasaXPS と同じ)。

## Report: 結果

各成分の位置・FWHM・真の半値全幅(Width)・面積とその標準偏差、RSF、面積/RSF の割合、χ² と縮約 χ² を表示します。**Copy** でタブ区切りの表としてコピーできます。不確かさは解での Jacobian から(残差の分散で尺度合わせ)求め、背景の不確かさは含みません。結んだパラメータは結んだ先の不確かさを、固定したパラメータは 0 を持ちます。

## 作られるもの

フィットするたびに、スペクトルと同じ長さ・スケーリングで(領域の外は NaN)次の wave を作り直します。

- `fit_<名前>`: 背景 + 全成分(エンベロープ)
- `fit_<名前>_bg`: 背景
- `fit_<名前>_A`, `_B`, …: 背景に載せた各成分
- `fit_<名前>_res`: データ − エンベロープ
- `fit_<名前>_BE`: 結合エネルギー(kinetic や Shift でスペクトルの X と違うときだけ)

グラフ `XPS_<名前>` に、反転した結合エネルギー軸、上に残差、凡例付きで表示します。2回目からは同じグラフを更新します(色や軸を変えたものはそのまま)。

## Python から

ウィンドウの操作は次の呼び出しと同じです。履歴からコピーして、別のスペクトルに使えます。

```python
r = op.xps_fit("C1s", [
    {"name": "C-C", "shape": "GL(30)", "position": 284.8, "fwhm": 1.1},
    {"name": "C-O", "position": 286.3, "constraints": {"position": "A+1.5", "fwhm": "A"}},
    {"name": "O-C=O", "position": 288.8, "constraints": {"position": "288, 290", "fwhm": "A"}},
], region=[281, 293], shift=-0.4)
r["C-O"]["position"]                         # 成分の値(文字か名前で)
op.result(r.name).apply(["C1s_2", "C1s_3"])  # 同じモデルを別のスペクトルに
```

## 線形

u = (BE − E)/F、m は %、u > 0 が高結合エネルギー側です(CasaXPS マニュアル 2.3.15 rev 1.3、p. 55 と p. 301)。

| 線形         | 式                                                                                   |
| ------------ | ------------------------------------------------------------------------------------ |
| `GL(m)`      | exp(−4 ln2 (1 − m/100) u²) / (1 + 4 (m/100) u²)(ガウスとローレンツの積)              |
| `SGL(m)`     | (1 − m/100) exp(−4 ln2 u²) + (m/100) / (1 + 4u²)(和)                                 |
| `GL(m)T(k)`  | 高結合エネルギー側で GL + (1 − GL) exp(−k u)。k が小さいほど裾が長い                 |
| `SGL(m)T(k)` | 同じく SGL に裾を付けたもの                                                          |
| `LA(α,β)`    | 高結合エネルギー側で (1 + 4u²)^(−α)、反対側で (1 + 4u²)^(−β)。金属の非対称なピークに |

- 面積は線形全体の面積です。ガウス関数を畳み込んでも面積は変わりません
- F が真の半値全幅になるのは GL(0)、GL(100)、SGL(m) で裾もガウスもないときだけです(GL(30) では 0.961 F)。真の幅は Report の **Width** に出ます
- CasaXPS の `LA(α,β,m)` の m は換算が公開されていないため、代わりに **Gauss** にガウス関数の FWHM を eV で与えます

## 限界

- 1つのスペクトルの1つの領域をフィットします。サーベイからの定量(複数の領域の面積と RSF からの原子濃度)は、例のプラグイン [xps](https://github.com/ks250206/OresmePro/tree/main/examples/plugins/xps) の `quantify` を使います
- 背景はフィットの間は固定です(active Shirley はありません)。不確かさに背景の不確かさは入りません
