現在の **Open OresmePro** はアプリの起動リンクです。コード例をコピーし、アプリのコマンドウィンドウへ貼り付けて実行します。

## 将来の拡張

1. リンクには `sample=sine-v1` のようなバージョン付き ID を指定します。アプリがその ID を同梱の許可リストで照合し、対応するコードを表示します。任意のコード、外部 URL、ファイル名はリンクの入力として受け取りません。
2. 実行前にコード全文と実行先を表示します。既存の Experiment に影響するため、新規 Experiment を初期選択とし、ユーザーが確認してからコマンドウィンドウに挿入します。実行には通常の実行操作を使います。
3. 未知の ID、非対応バージョン、取得失敗ではエラーを表示し、Experiment を変更せずにコピー手順へ案内します。公開時にサンプル ID とコードを両方の成果物で揃えます。

Python は作業中の Wave とファイルにアクセスできます。ユーザーが開いた URL やメッセージを契機に実行する経路を作ると、外部から誘導された操作でデータが変更されます。同じオリジンのサイトはブラウザーストレージを共有するため、ドキュメントのスクリプトや配信元もアプリと同じ信頼境界として扱います。
