# OresmePro

OresmePro は、実験データの読み込み・表編集・グラフ作成・解析を 1 つのワークスペースで行う、
ブラウザで動く科学データ解析環境です。WaveMetrics の Igor Pro の作業感
(wave、グラフ、コマンドウィンドウ、「GUI 操作がすべてコマンドとして履歴に残る」こと)を手本にしつつ、
スクリプト言語には Python を採用します。

> **現在の状態: 設計段階。** このリポジトリにはまだ実装がありません。
> 以下は [scispace_poc](https://github.com/ks250206/scispace_poc) での試作を踏まえた設計方針で、確定仕様ではありません。

## 名前の由来

名前は 14 世紀フランスの学者 **ニコル・オレーム**(Nicole Oresme, 1320 頃–1382)にちなみます。

オレームは『質と運動の図形化について』(*Tractatus de configurationibus qualitatum et motuum*, 1350 年代)で、
変化する量を図として描く方法を示しました。横方向に時間などの広がり(*longitudo*)を、
縦方向にその時点での強さ(*latitudo*)をとるもので、デカルトの座標幾何学より約 300 年早く、
**世界で初めてグラフをプロットした人物**とされています。
彼はこの図を使い、等加速度運動で進む距離が「速度–時間グラフの下の面積」に等しいこと(平均速度定理)を幾何学的に証明しました。

データを図にして初めて見えるものがある、という OresmePro の中心にある考えは、オレームのこの仕事に遡ります。

## 目指すもの

- **グラフが主役。** そのまま論文に載せられる品質の図を、画面上で直接いじって作れること。
- **すべての操作がコマンド。** メニューやダイアログでの操作は Python のコードとして履歴に残り、そのまま再実行・スクリプト化できること。
- **本物のシェルのように使えるコマンドウィンドウ。** 履歴は消えず、検索でき、補完が効くこと。
- **Python がそのまま使える。** Blender の `bpy` のように、アプリの中身を Python モジュールから操作できること。

## 設計方針

### データモデル: wave とデータフォルダ

Igor と同じく、データの単位は **wave**(名前・スケーリング・単位・ノートを持つ多次元配列)です。
表は wave を列として並べたビュー、グラフは wave を参照するビューで、wave を書き換えると表もグラフも追従します。
wave はデータフォルダの木(`root:` 以下)に置きます。

wave の実体は Python を動かす Web Worker の中に NumPy 配列として置き、
画面側は「いま見えている範囲」だけ(表なら表示中の行、グラフなら画素数ぶんに間引いた点列)を受け取ります。
これにより、数百万点の wave でも UI スレッドを止めません。

### グラフ

既存のチャートライブラリは使わず、専用のレンダラを書きます。

- グラフの定義から**描画命令のリスト**(線・パス・文字)を作る純粋関数を中心に置き、
  同じリストを Canvas 2D(画面表示)、SVG、PDF(書き出し)に流します。画面と書き出しが一致します。
- 余白は文字の実測幅から自動で決めます。
- 目盛りは Igor 流の規則で自前生成します(1-2-5 刻みの主目盛りと副目盛り、対数軸の 2–9 副目盛り、
  指数の括り出し、単位に応じた SI 接頭辞、日付・時刻軸)。
- 大きな wave は画素列ごとの最小値・最大値に間引いて描きます。
- 操作も Igor に合わせます: マーキーで囲んで拡大/縮小、軸や trace のダブルクリックで設定ダイアログ、
  カーソル A/B と情報パネル、自動スケール、テキストボックス・凡例・タグ。
- 左右・上下の複数軸、自由軸、軸の分割表示、画像プロット、等高線は段階的に追加します。

### コマンドウィンドウ

Igor と同じ「上に履歴、下にコマンドライン」の構成にします。

- **コマンドライン**は CodeMirror 6。複数行編集、構文ハイライト、Python の補完、日本語入力が普通に使えます。
- **履歴**は仮想スクロールするブロックの列で、1 ブロックが 1 回の実行(入力・出力・所要時間・成否)です。
  出力には ANSI カラーのテキストのほか、表やグラフのサムネイルも置けます。
- 履歴はプロジェクトごとに永続化し、シェルと同じ操作で引けます:
  `↑`/`↓` は入力中の文字列での前方一致検索、`Ctrl+R` はインクリメンタル検索、
  入力中には直近の一致候補を薄く表示します(fish の autosuggestion 相当)。
- GUI での操作も、等価な Python コードとして同じ履歴に入ります。

### スクリプト: Python

[Pyodide](https://pyodide.org/)(WebAssembly 版 CPython)を Web Worker で動かし、
その上で IPython の対話シェルを使います。NumPy / SciPy / pandas がそのまま使え、
`%cd`・`%ls`・`obj?` などのマジックも使えます。

アプリの操作は `oresme` モジュールから行います。

```python
import numpy as np
import oresme as op

x = np.linspace(0, 10, 1000)
w = op.make("signal", np.sin(x) * np.exp(-x / 5))
w.set_scale(x0=0, dx=x[1] - x[0], unit="s")

g = op.display(w)
g.axis("left").label = "Amplitude (V)"
g.trace("signal").color = "red"
```

(API は検討中の案です。)

### 保存

プロジェクトはブラウザの OPFS(Origin Private File System)上のディレクトリとして保存します。
wave は `.npy`、グラフや表の定義は JSON とし、まとめて 1 ファイルに書き出すこともできるようにします。
